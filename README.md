# `treebeard`
Soft Decision Trees for Next-Gen Trigger at CMS.   
  
This repo has two parts:

1. **SDT implementation** — data preprocessing, dataloader construction, model architecture, training, Python-side quantisation studies for a Soft Decision Tree ([Frosst & Hinton 2017](https://arxiv.org/abs/1711.09784)) trained on CMS L1T primitives.
2. **High Level Synthesis** — conversion to Vitis HLS firmware using [`conifer`](https://github.com/thesps/conifer)'s existing single-tree hard decision tree backend (specifically using [`ydf`](https://github.com/google/yggdrasil-decision-forests)'s Gradient Boosted Decision Tree), adapted into a Soft Decision Tree architecture.  

## Repo Layout
- `treebeard/` — core Soft Decision Tree implementation.
- `scripts/` — training and evaluation scripts
- `jupyter/` — date preprocessing, dataloader construction, SDT architecture studies, Python-side fixed-point quantisation studies.
- `conifering/` — cpp and HLS backend generated by `conifer`. single YDF-trained decision tree → conifer → xilinxhls. Starting point for SDT conversion to HLS.
